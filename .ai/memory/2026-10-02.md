# 2026-10-02 — Full normalization refactor

## Starting point (the trap)

The brief said "fix known defects", so the first move was to take a baseline. **`npm run ts-check` was red: 23 errors.** Neither was a code defect:

- `@lucide/svelte` was installed at 1.50.0 while the lockfile pins 1.48.0, and its `dist/lucide-svelte.d.ts` barrel was missing → 22 "Could not find a declaration file" errors.
- A stale `web/node_modules/vite` (6.4.3) shadowed the hoisted one, so `web/vite.config.ts` saw two incompatible `Plugin` types.

`npm ci` unlinks first and aborted on an `EPERM` against `lightningcss.win32-x64-msvc.node`, leaving `node_modules` half-deleted. Recovery was: stop the `npm run dev` tree (taskkill on the PIDs, never `-Name node`), `npm ci` again — antivirus held the file this time, so `npm install`, which re-adds without unlinking — then re-extract `@lucide/svelte` from its lockfile tarball. Revert the `license` line `npm install` adds to the lockfile.

Lesson recorded in MEMORY: **a wall of type errors can be a corrupt install.** Compare installed versions against the lockfile first.

## What changed

**Dead code.** `swDead` (written, never read), `barIconSize` (superseded by publishing `--bar-icon`), the dead `parts` array in `keepalivePrefix`. One e2e placeholder that only called `test.skip`, and one tautology — `expect(syncSeen || true).toBe(true)` — whose test also could not have passed: the pagehide flush returns early when `pending === 0`, and the op was posted with a raw `fetch` that never reached the oplog. Rewritten to submit feedback through the sidebar and assert the keepalive body contains `fb_create`.

**i18n.** `'ERROR'` was hard-coded in `PhotoCard` and `Lightbox`; now `copy.errorGlyph`. Reaction chips gained `aria-label` + `aria-pressed` via `copy.reactions.toggle`.

**Store.** One `AdminCollection<T>` replaces both twins. Rollback toasts now compose _both_ the rollback text and the timeout hint — announcements previously lost the hint. Added the missing `copy.admin.poll.deleteRollback` / `reorderRollback`.

**Sliders.** `sliderKeyTarget()` in `base/lib/slider.ts` replaces two hand-written key switches, which had diverged: PageUp/PageDown moved ten _business units_ in `SingleSlider` and ten _percent of the track_ in `RangeSlider` — very different jumps under the `log` scale used for byte sizes. Fixed by deciding the semantics once.

**Tokens.** ~30 colour literals → tokens; `--color-dislike`, `--radius-card`, `--control-disabled-opacity` added. 13 magic milliseconds → `base/lib/motion.ts`, which reads the `@theme` block and converts a `cubic-bezier(...)` token into Svelte's `EasingFunction` (a CSS string does not typecheck there). The `0.3125` icon ratio appeared as a literal in 8 places while `topbarFit.ts` exported the constant; the bar now publishes `--bar-icon` / `--bar-badge`.

**Defects fixed.** `PhotoCard` selection snapped 1px — `border-2` with `border-width` outside the transition list. `VoteBlock` overrode `button:disabled{cursor:not-allowed}` with `disabled:cursor-default`. `App.svelte` faded the Turnstile overlay _in_ on the exit curve.

**Shared owners.** `num.ts`, `hover.ts`, `clipboard.ts`, `shared/json.ts`, `PollReferences.svelte`, `src/shared/json.ts`.

**Tests.** 24 → 21 web files with no coverage loss: `core.test.ts` folded into `syncEngine.test.ts`, `api.test.ts` split into `syncClient.test.ts` + `lease.test.ts` (its `postUpload` and deadline blocks already lived in `uploadClient.test.ts` / `request.test.ts`), `band.test.ts` folded into `layout.test.ts` + `settings.test.ts`, and the slider duplicate removed from `frontend.test.ts`.

## Second pass — the open questions, closed

The user settled the four items left standing, with one exception: **editor images are not deduplicated.**

1. **`putSha` deleted.** It had no production caller, and the `'editor'` purpose it wrote was therefore unreachable. The sha cache is now exactly what it is used for: `isKnownAlbumSha(db, sha)` returning a boolean, backed by the snapshot's hashes and replaced wholesale each sync. `ShaEntry`, `cacheKey`, and the cursor walk that preserved editor entries across a rebuild all went with it — the "keeping editor entries" behaviour was protecting rows nothing could write. `rebuildCache` is now a `clear()` plus one `put` per photo.
2. **The admin editor dialogs are modal.** The "Non-modal editor panel" comment was _why_ they had escaped `overlay.ts`; with that settled, both run through a new `EditorDialog.svelte` that owns the shell, scroll region, footer, focus trap, scroll lock and Escape. Each dialog passes only its body. `onMount(() => titleInput?.focus())` is gone — the overlay focuses the first focusable element, which also gives the poll dialog a focus target it never had.
3. **Admin writes take their locale as an argument.** `adminClient` read `activeLocale()` for the body while the store filed the optimistic row under `contentLocale`. Every create/update/reorder now takes `LocaleCode` explicitly, and the store passes `this.contentLocale`.
4. **One pill measurement.** `SegmentedControl` summed `invisible` label-copy widths; `SortPill` used a clone probe. The sum was the "hidden copies lie" trap MEMORY warns about, so the clone probe won and moved to `pillMeasure.ts`. Both the admin tabs and the gallery sort pill now report comparable widths through the same action — previously the admin path never even forwarded `onWidths`.
5. **One test convention.** 20 files across both suites converted from `describe`/`it`/`expect` to `test` + `node:assert/strict`, flattening each `describe`/`it` pair into `test('Group: Case')`. Test counts are unchanged (59 + 57). Four subagents did the bulk in parallel, each verifying its own files.

Converting surfaced one real semantic difference worth keeping: `expect(...).toEqual` ignores `undefined`-valued keys, `assert.deepEqual` does not. `uploadClient.test.ts` had been passing only because of the looser check — the result carries `detail: undefined`, now asserted explicitly.

## Left standing

- **`putPendingUpload`/`clearOps` are test-only helpers living in production modules.**
- **`SegmentedControl` and `SortPill` now share one measurement, but `SortPill` is a thin wrapper** over `SortTabs` + `pillMeasure`. If a third segmented pill ever appears it can skip both.
- e2e still needs the real local stack; the rewritten pagehide test in `pipeline.spec.ts` has not been executed locally.
