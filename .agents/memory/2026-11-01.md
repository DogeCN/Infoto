# 2026-11-01 — consolidated WS spec implemented (op store + coordinator + admin ops)

The consolidated spec from the user's other session was implemented on
`wip/do-websocket-migration` across three commits (921f4d7 server, ecf95fd client):

- **The DO is the sequential op store.** Ops log to DO SQLite (whole op JSON: type,
  target/targetSha, payload, cid, ct — marks carry their target at op level, so the log
  must store the WHOLE op, never just the payload). An in-memory snapshot folds each op;
  D1 is the cold snapshot store, touched at the edges: upload ops no longer write D1 in
  the hot path — `/l/:id36` queries the DO first (internal photo lookup) and falls back
  to D1; migrate export triggers an internal flush (fold log → D1, clear), import
  rehydrates the DO afterwards.
- **Timestamps: server-authoritative ts + client ct preserved.** The DO stamps ts per op;
  the client's commit time rides `ct` and display times take `min(ct, ts)`. This
  reconciles the two conflicting instructions (summary item 3 vs the earlier offline
  message).
- **Catch-up:** hello carries lastSeq; the DO answers incremental ops after it, or a
  whole snapshot when lastSeq is 0/below the retained window. Feedback ops are
  root-only on the wire.
- **Kick-dedup:** a newer connection of the same user closes the older one (4001); the
  kicked client shows the sync button and does not auto-reconnect (user-confirmed).
- **Client:** `sync/coordinator.ts` (SharedWorker core + shell) owns the single
  WebSocket, lastSeq (localStorage), backlog flush, and ack bookkeeping by cid. Tabs
  queue into the shared oplog and apply broadcast ops live (user-confirmed: real-time).
  The engine stamps cid + ct, skips its own echoes, applies foreign ops through
  appStore.applyServerOps (all op types). Admin CRUD queues as ops; optimistic creates
  are replaced when the echo assigns the real id; a dropped op rolls back with
  copy.api refusal text (read dynamically — the copy gate's one dynamic subtree).
- **Not done / rejected:** videoBudget stays deleted (the viewport top-band rule in
  WaterfallLayout supersedes the fixed-3 budget; spec item 17 is the operative one).
  e2e mocks still speak HTTP `/sync` and need a routeWebSocket rework.
